# CASTLOG 캐스트로그 — 플랫폼 랜딩페이지

창업교육·창업컨설팅 기업을 위한 통합 플랫폼 **캐스트로그(CASTLOG)** 의 공식 랜딩페이지입니다.
Claude Design 핸드오프 시안(`CASTLOG 랜딩페이지.dc.html`)을 기준으로 제작된 정적 웹페이지입니다.

## 미리보기

- 로컬에서 `index.html` 을 브라우저로 열면 바로 확인할 수 있습니다.
- 별도의 빌드 과정이 없는 순수 HTML/CSS 정적 사이트로, Vercel · Netlify · GitHub Pages 등에 그대로 배포할 수 있습니다.

```bash
# 간단한 로컬 서버 실행 예시
npx serve .
# 또는
python3 -m http.server 8000
```

## 구조

```
.
├── index.html          # 랜딩페이지 전체 마크업 (섹션별 주석 포함)
└── assets/
    └── css/
        └── style.css   # 디자인 토큰(브랜드 컬러 CSS 변수) + 전체 스타일
```

## 브랜드 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--navy` | `#0B1D3A` | 딥 네이비 (헤드라인, 워드마크) |
| `--blue` | `#246BFF` | 프라이머리 블루 (포인트, 링크) |
| `--blue-deep` | `#1D4FD8` | 딥 블루 (CTA 버튼, 차트 강조) |
| `--sky` | `#6CA8FF` | 라이트 블루 (보조 포인트, 차트) |
| `--amber` | `#FFB000` | 앰버 (강조 버튼, 워크플로우 배지) |

본문 서체는 **Pretendard**, 워드마크 서체는 **Poppins** (모두 CDN 로드)입니다.
로고 심볼은 그라데이션이 적용된 인라인 SVG(`#clgSym`)로 정의되어 페이지 전체에서 `<use>`로 재사용됩니다.

## 페이지 구성

1. **헤더** — 로고, GNB(제품/기능/전자결재/전문가 관리/요금 안내/고객지원), 로그인·무료 체험 신청
2. **히어로** — 카피 + CTA + 제품 대시보드 목업(통계 카드·프로젝트 현황·전자결재 도넛 차트·지급 추이 차트)
3. **핵심 가치** — 10계층 보안 / 전문가 신원 관리 / 전자결재 엔진 / 비용·지급 관리 / 서류 자동 관리 / 멀티테넌트 SaaS
4. **문제 → 해결** — 기존 업무의 문제점과 캐스트로그의 해결책 비교
5. **21단계 워크플로우** — 궤도형 다이어그램 + 프로젝트 진행 현황 예시 카드
6. **CTA 밴드** — 무료 체험·도입 상담 안내
7. **푸터** — 제품 / 고객지원 / 회사 / 법적 고지
