# 운영 환경변수 설정 가이드

캐스트로그가 외부 서비스와 연결되려면 **키(비밀번호 같은 문자열)** 를 등록해야
합니다. 이 문서는 지금 필요한 세 가지를 다룹니다.

| 키 | 무엇이 켜지나 | 없으면 | 급한가 |
|---|---|---|---|
| `PLATFORM_ADMIN_EMAILS` | 관리자 모드 전환 버튼 | 버튼이 안 보임 | **높음** |
| `ANTHROPIC_API_KEY` | 사용법 도우미 챗봇 + 상담게시판 | 챗봇이 "아직 켜지지 않았습니다" | 중간 |
| `OPINET_API_KEY` | 출장품의 유류비 자동 조회 | 유가를 손으로 입력 | 낮음 |

---

## 공통 — 환경변수를 어디에 넣나

캐스트로그는 **Vercel**에 배포됩니다. 키는 코드가 아니라 Vercel에 저장합니다
(코드에 적으면 GitHub에 그대로 올라가 누구나 볼 수 있습니다).

### 넣는 순서 (세 키 모두 동일)

1. 브라우저에서 <https://vercel.com> 로그인
2. 캐스트로그 프로젝트 클릭
3. 상단 **Settings** 탭
4. 왼쪽 메뉴 **Environment Variables**
5. **Key** 칸에 변수 이름, **Value** 칸에 값을 붙여 넣기
6. 적용 범위(Environments)는 **Production · Preview · Development 모두 체크**
7. **Save**

> ⚠️ **저장만 하면 아직 적용되지 않습니다.** 환경변수는 배포 시점에 주입되므로
> 새로 배포해야 반영됩니다. Vercel의 **Deployments** 탭 → 맨 위 배포의 **⋯**
> 메뉴 → **Redeploy** 를 누르면 1~2분 뒤 적용됩니다.

## 1. `PLATFORM_ADMIN_EMAILS` — 관리자 모드 전환

### 왜 필요한가

넥스트랩 직원도 평소에는 **자기 회사(넥스트랩) 테넌트 계정**으로 일합니다.
그러다 다른 회사의 테넌트를 만들거나, 모듈 요청을 승인하거나, 챗봇 상담게시판을
볼 때만 **관리자 모드**로 올라가야 합니다.

이때 문제가 하나 있습니다. 관리자 모드는 **모든 회사의 경계를 넘는 권한**입니다.
그래서 "누가 올라갈 수 있는가"의 명단을 데이터베이스에 두면 위험합니다 —
데이터베이스에 쓸 수 있게 된 공격자가 자기 이메일을 명단에 넣어 스스로를
관리자로 만들 수 있기 때문입니다.

환경변수는 **앱 바깥(Vercel 설정)** 에 있습니다. 앱을 통해서는 고칠 수 없으므로
그 경로가 막힙니다. 이것이 명단을 여기 두는 이유입니다.

### 값 형식

이메일 주소를 쉼표로 구분합니다. 대소문자는 구분하지 않습니다.

```
jinkidi@gmail.com
```

여러 명이라면:

```
jinkidi@gmail.com,manager@nextlab.co.kr
```

### 작업 순서

1. 위 **공통** 순서대로 Vercel에 `PLATFORM_ADMIN_EMAILS` 추가
2. Redeploy
3. castlog.kr에 넥스트랩 CEO 계정으로 로그인
4. 화면 **오른쪽 위**, 이메일 왼쪽에 남색 **`관리자 모드`** 버튼이 보이면 성공
5. 누르면 `castlog.kr/platform-admin` 으로 이동합니다
6. 관리자 모드 화면 오른쪽 위 **`기업 모드로`** 버튼으로 원래 자리로 돌아옵니다

### 확인·문제 해결

- **버튼이 안 보인다** → 로그인한 계정의 이메일과 환경변수의 이메일이 정확히
  같은지 확인하세요(오타·공백). Redeploy를 했는지도 확인하세요.
- **눌렀는데 되돌아온다** → 명단에 없는 계정입니다. 조용히 원래 자리로
  보냅니다(존재 여부를 알려 주지 않기 위해서입니다).
- 진입·이탈은 **감사로그**에 남습니다. 관리모드 → 감사로그에서
  `platform_mode.enter` / `platform_mode.exit` 로 확인할 수 있습니다.

## 2. `ANTHROPIC_API_KEY` — 사용법 도우미 챗봇

### 왜 필요한가

화면 오른쪽 위 **도우미**는 사용자의 질문을 이해하고 답을 만들어야 합니다.
그 언어 능력은 Anthropic(클로드)의 서버가 제공하며, 우리 서버가 그쪽에
요청을 보낼 때 **누구의 요청인지 증명하는 열쇠**가 이 키입니다.

이 키 하나가 두 가지를 함께 켭니다.

1. **도우미 답변** — "수락서는 어디서 보내나요?" 같은 질문에 대한 안내
2. **챗봇 상담게시판** — 대화 중 흘린 불편·오류·이해 실패를 자동으로 분류해
   관리모드 게시판(건의/요청 · FAQ)에 쌓는 기능

키가 없으면 도우미는 **거짓말을 지어내지 않고** "아직 켜지지 않았습니다"라고
답합니다. 다른 기능에는 영향이 없습니다.

### 키 발급 순서

1. <https://console.anthropic.com> 접속 → 회원가입/로그인
   (회사 이메일로 가입하시길 권합니다)
2. 왼쪽 메뉴 **Settings** → **API keys**
3. **Create Key** 버튼
4. 이름은 알아보기 쉽게 (예: `castlog-production`)
5. 만들어진 키(`sk-ant-` 로 시작하는 긴 문자열)를 **바로 복사**
   > ⚠️ 이 화면을 닫으면 키를 **다시 볼 수 없습니다.** 잃어버리면 새로 만들어야
   > 합니다. 안전한 곳(회사 비밀번호 관리도구)에 함께 보관하세요.
6. **결제 등록** — 왼쪽 메뉴 **Billing** 에서 카드 등록 후 크레딧 충전.
   등록하지 않으면 호출이 거부됩니다.

### 비용 감각

도우미는 짧은 문답용으로 맞춰 두었습니다(답변 최대 700 토큰, 분류 250 토큰).
직원 20명이 하루 몇 번씩 물어보는 정도라면 **월 몇 천 원~수만 원** 선입니다.
Anthropic 콘솔의 **Usage** 에서 실제 사용량을 볼 수 있고, **Billing → Limits**
에서 월 상한을 걸어 두면 예상 밖 지출을 막을 수 있습니다.

### 작업 순서

1. 위 **공통** 순서대로 Vercel에 `ANTHROPIC_API_KEY` 추가 (값은 `sk-ant-...`)
2. Redeploy
3. castlog.kr 로그인 → 오른쪽 위 **도움말** 버튼
4. "전문가 섭외는 어떤 순서로 하나요?" 를 눌러 답이 오면 성공

### 확인·문제 해결

- **"아직 켜지지 않았습니다"** → 키가 등록되지 않았거나 Redeploy 전입니다.
- **"AI 응답 오류 (401)"** → 키가 잘못되었거나 삭제되었습니다. 새로 발급하세요.
- **"AI 응답 오류 (429)"** → 크레딧이 없거나 한도를 넘었습니다. Billing 확인.
- 상담게시판은 `castlog.kr/platform-admin/help-board` (관리자 모드에서 접근).
  대화를 몇 번 나눈 뒤 들어가면 항목이 쌓입니다. **연습모드에서 나눈 대화는
  게시판에 올라오지 않습니다** — 연습은 운영 신호가 아니기 때문입니다.

### 개인정보 관련 (알아 두실 것)

- 도우미에게는 **회사 이름·직급·사용 모듈·현재 화면 경로**만 전달됩니다.
- **실제 프로젝트명·전문가 이름·금액은 전달되지 않습니다.**
- 상담게시판에는 **대화 원문이 저장되지 않습니다.** 정리된 제목·요약과 화면
  경로만 남습니다.
- 도우미는 결재 승인·지급 금액 같은 **업무 판단을 대신하지 않습니다**
  (CLAUDE.md §14-1).

## 3. `OPINET_API_KEY` — 출장품의 유류비 자동 조회

### 왜 필요한가

**전자결재 → 출장품의**에서 유류비를 계산할 때, 오늘의 기름값이 필요합니다.
오피넷(한국석유공사 유가정보시스템)은 **전국 평균 판매가**를 공개 API로
제공합니다. 이 키가 있으면 휘발유·경유·LPG 단가가 **자동으로 채워집니다**.

키가 없어도 출장품의는 **그대로 동작합니다.** 다만 단가를 담당자가 직접
입력해야 하고, 그 값이 맞는지 아무도 검증해 주지 않습니다. 자동 조회는
"이 숫자는 오늘 오피넷 값"이라는 근거를 남기는 의미가 큽니다.

> 참고: 거리 자동 계산은 별도로 **네이버 지도 키**(`NAVER_MAP_CLIENT_ID`,
> `NAVER_MAP_CLIENT_SECRET`)를 씁니다. 유가와 거리는 서로 독립이라 하나만
> 설정해도 그 부분만 자동으로 채워집니다.

### 키 발급 순서

1. <https://www.opinet.co.kr> 접속
2. 상단 메뉴에서 **정보제공** → **Open API** (또는 사이트 하단 `Open API` 링크)
3. **API 키 발급 신청** — 회원가입이 필요합니다
4. 신청서에 사용 목적을 적습니다
   (예: "사내 출장비 정산 시스템의 유류비 자동 계산")
5. 승인되면 **개인 인증키(문자열)** 가 발급됩니다
   - 즉시 발급되는 경우도 있고, 담당자 검토로 1~2일 걸리는 경우도 있습니다
6. 발급된 키를 복사

### 작업 순서

1. 위 **공통** 순서대로 Vercel에 `OPINET_API_KEY` 추가
2. Redeploy
3. castlog.kr 로그인 → **전자결재 → 출장품의**
4. 연료 종류를 고르면 단가가 자동으로 채워지면 성공

### 확인·문제 해결

- **"오피넷 API 키(OPINET_API_KEY)가 설정되지 않았습니다"** → 등록 전이거나
  Redeploy 전입니다.
- **"오피넷이 유가를 반환하지 않았습니다(키 권한 확인)"** → 키는 등록됐지만
  해당 API 사용 권한이 없습니다. 오피넷에서 **평균판매가격 API** 사용 신청이
  되어 있는지 확인하세요.
- **"오피넷 응답 오류 (HTTP 4xx)"** → 키 문자열이 잘못되었을 가능성이 큽니다.
- 실패해도 화면은 **손 입력으로 넘어갑니다** — 품의 작성 자체가 막히지는
  않습니다.

## 정리 — 지금 하실 일

| 순서 | 작업 | 걸리는 시간 |
|---|---|---|
| 1 | Vercel에 `PLATFORM_ADMIN_EMAILS` 추가 → Redeploy | 5분 |
| 2 | Anthropic 콘솔에서 키 발급 + 결제 등록 → Vercel 추가 → Redeploy | 15분 |
| 3 | 오피넷 Open API 키 신청 (승인 대기 가능) → Vercel 추가 → Redeploy | 신청 10분 + 대기 |

1번은 지금 바로 하실 수 있고, 3번은 승인 대기가 있을 수 있으니 **먼저 신청만
걸어 두시길** 권합니다.
