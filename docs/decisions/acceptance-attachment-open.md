# 수락서 첨부 — 화면 열람 전용 → 비렌더 형식은 '원본 열기' (개정 2026-09-05)

## 판정
수락서 동봉 자료는 종전 확정("화면 안에서만 열람, 다운로드 경로 없음")을
**부분 개정**한다.

- PDF·이미지(JPG/PNG/GIF): 종전대로 화면 안 인라인 열람.
- 엑셀(xls/xlsx)·한글(hwp/hwpx)·파워포인트(ppt/pptx)·워드(doc/docx):
  브라우저가 그릴 수 없으므로 **서명 만료 URL을 새 창으로 여는 '원본 열기'**를
  제공한다. 사실상 내려받기다.

## 근거
기획 지시(2026-09-05): 수락서 첨부에 xls·hwp·ppt 등 다양한 형식을 허용한다.
허용하면서 열람 수단을 주지 않으면 첨부가 죽은 기능이 된다. 민감서류를 외부
변환 서비스로 보내 미리보기를 만드는 방식은 보안 원칙상 채택하지 않는다
(components/documents/document-preview.tsx와 같은 판단).

## 유지되는 것
- 공개 URL은 만들지 않는다. 열람 주소는 서명 만료 URL(10분)뿐이다.
- 열람은 감사로그(engagement_acceptance.view)에 남는다.
- 기업 담당자용 PDF 다운로드 규칙(서명 완료 건만)은 그대로다.
