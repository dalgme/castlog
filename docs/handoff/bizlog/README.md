# 비즈로그 인계 초안

이 폴더의 파일은 **캐스트로그의 규칙이 아니다.** 별도 레포에서 시작할 로컬 프로그램
'비즈로그'의 설계 초안이며, 새 레포를 만들 때 옮겨 간다.

- `design.md` — 설계 문서 (테이블·키 관리·퇴사 처리·서류별 주민번호 필요 여부)
- `bizlog-claude-md.md` — 새 레포의 `CLAUDE.md`로 쓸 초안.
  **여기서는 일부러 `CLAUDE.md`라는 이름을 쓰지 않았다** — 그 이름이면 클로드코드가
  이 폴더의 디렉터리 규칙으로 읽어, 캐스트로그 §11-3(주민번호 보유 금지)과
  정반대인 규칙이 캐스트로그 작업에 섞인다.

두 프로그램의 경계와 연동 계약의 정본은 `docs/integrations/bizlog-contract.md`다.

새 레포에서 시작하는 순서:
1. 빈 레포 생성 → `bizlog-claude-md.md`를 `CLAUDE.md`로 복사
2. `design.md`와 `bizlog-contract.md`를 `docs/`에 복사
3. 클로드코드를 열고 "docs/design.md 1단계부터 시작" 으로 착수
